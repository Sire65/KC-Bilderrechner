3. Kopiere den kompletten Inhalt des entpackten Pakets in diesen Zielordner.

5. Prüfe, dass images/ exakt 9 PNG-Dateien enthält.

7. Führe git status und git diff --stat aus und kontrolliere, dass ausschließlich der neue Archivordner ergänzt wird.
8. Commit-Nachricht: Archive KC studio image series 2026-09-11
9. Push auf main, falls erlaubt. Falls main geschützt ist: Branch kc-image-archive-2026-09-11 erstellen, pushen und PR gegen main anlegen.
