- heller Creme-/Beige-Hintergrund
- kontrastreiche Produktdarstellung
- Glas bzw. Flasche zentral bzw. im unteren/mittleren Bereich
- Zutaten/Symbole möglichst oben links, damit spätere Beschriftungen nicht verdeckt werden
- keine eingebrannten Produkttexte bei den Studio-Motiven
